# Tabler HTML Static Build

A ready-to-use static HTML build of [Tabler](https://tabler.io/), the open-source dashboard UI kit.

This repository provides the compiled HTML, CSS, JavaScript, and assets, so you can use Tabler without installing Node.js, Astro, or other build tools.

## Version

- **Tabler version:** 1.7.3
- **Format:** Static HTML
- **Build:** Compiled from the official Tabler source code
- **License:** See the original project and third-party dependency licenses before redistribution.

## Features

- Ready-to-use HTML pages.
- Compiled CSS and JavaScript.
- Static assets included.
- No Node.js or build process required to use the files.
- Suitable for PHP applications and other backend technologies.

## Installation

1. Download or clone this repository.
2. Extract the files if you downloaded the ZIP.
3. Copy the files to your web server.
4. Open the corresponding HTML page in your browser.

## Usage with PHP and Laravel

You can use these static files as a starting point for your PHP or Laravel projects.

Simply integrate the HTML structure into your PHP views or Laravel Blade templates and adapt the asset paths as needed.

No Astro or Node.js installation is required to use the compiled files.
